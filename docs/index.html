为什么是 Sona

播放器不该在断网时
变成一块空白。

Sona 从一开始就围绕本地文件设计：先让播放可靠，再把云同步当作增强，而不是依赖。曲库保存在本机 SQLite 数据库里，扫描、收藏、歌单和播放记录离线时都照常工作。

安装前请读一下

官方版本从 0.4.51 起使用永久 Android 签名，0.5.0 APK 可以直接覆盖安装 0.4.51。如果装过 0.4.50 开发签名版或其他签名的版本，请先导出完整备份并保留媒体文件，卸载一次后再安装 0.5.0。卸载会清除 Sona 的私有数据库、设置和自动快照，但不会删除共享目录里的媒体文件。

Windows 安装包目前没有 Authenticode 签名，SmartScreen 可能提示“未知发布者”。请只从本页面或 GitHub Release 下载。
