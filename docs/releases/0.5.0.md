# Sona 0.5.0 Public Preview

**English** · [简体中文](#简体中文) · [Download](https://github.com/Owl-Lee/Sona-Player/releases/latest)

Sona 0.5.0 is a data-safety, metadata-control, performance, and reliability release for Windows and Android. Local playback remains the core experience; cloud sync and online identification remain optional enhancements.

## Highlights

### Recoverable cloud management

- Deleting a cloud track now moves its cloud copy to a recycle bin for 30 days instead of immediately destroying it.
- A just-deleted track can be restored from the confirmation message, and any recycled track can be restored from the recycle-bin view.
- Permanent deletion and emptying the recycle bin are explicit owner-only operations. They remove the cloud record and orphaned cloud media, but never delete the local file.

### Complete backup and restore

- A manually exported `.sonabackup` is self-contained: it includes the SQLite library, Sona settings stored in that database, imported songs and MVs, and managed artwork, covers, and custom backgrounds.
- Every backup is streamed, checksummed, fully verified before restore, and restored on a cold start with a pre-restore database rollback copy.
- Lightweight automatic recovery snapshots keep the latest three database-and-artwork states without repeatedly copying the entire media library. They are for same-device recovery; use a manually exported complete backup before changing devices, uninstalling, or migrating signatures.
- Account sessions and cloud credentials are not included. Sign in again after restoring on another installation.
- Complete backups are not encrypted. Store them as carefully as the media and personal library data they contain.

### Metadata you can control

- Smart identification still combines embedded tags, filename cleanup, MusicBrainz, and optional Chromaprint / AcoustID matching.
- Track information is previewed before it changes the library.
- You can manually edit the title, artist, album, and artwork.
- Identification and manual edits create a per-track history, with safe undo that refuses to overwrite a newer unrelated change.

### Performance modes

- Choose **Full effects**, **Energy saver**, or **Motion off** in Settings.
- The selected mode scales animation cadence, particles, blur, image cache budgets, vinyl motion, and Windows video output while preserving the wallpaper and theme colors.
- The theme picker and full-screen effects avoid repeated image decoding and unnecessary native video-surface churn.

### Playback and mobile reliability

- Rapid play, pause, previous, and next commands are serialized so the audio, title, artwork, duration, queue highlight, and MV/vinyl view converge on the same current track.
- Queue changes, media-capability detection, cloud-click concurrency, deletion boundaries, backup corruption, metadata undo, and performance-mode persistence have dedicated regression coverage.
- The signed Android package was exercised on an Android 16 device for cold launch, background/resume, media-session availability, critical-memory callback survival, and relaunch without clearing app data.
- Phone calls, Bluetooth devices, and manufacturer power-saving policies vary by device. Please report device-specific interruptions with the device model and Android version.

## Downloads and installation

Release assets use stable filenames, and every package has a matching `.sha256` sidecar attached to this release.

- **Windows installer:** `Sona-Windows-x64-Setup.exe`
- **Windows portable:** `Sona-Windows-x64.zip` — extract the complete archive before running `sonar_vault.exe`.
- **Android:** `Sona-Android.apk`

### Android signing and upgrades

The permanent Sona Android signing identity was introduced in the official 0.4.51 release. The official 0.5.0 APK can update official 0.4.51 installations in place without clearing app data.

The older 0.4.50 preview used a development certificate, and locally built or third-party APKs may use another certificate. Android cannot install 0.5.0 over an APK signed by a different identity. If Android reports a signature conflict, first preserve your original media and any cloud data you need, then uninstall the differently signed build once and install the official 0.5.0 APK. Uninstalling clears Sona's app-private database, settings, and automatic snapshots, but does not delete media in normal shared folders.

### Windows signing notice

The Windows packages are not Authenticode-signed yet. Microsoft Defender SmartScreen may show **Unknown publisher**. Download only from the official Sona website or this GitHub Release, then verify the matching `.sha256` sidecar before running the package.

> Sona 0.5.0 remains a public preview. Keep independent copies of important media and an externally exported complete backup.

## Production and release validation

- The cloud recycle-bin and owner-only deletion policies were applied to the production Sona Cloud database through migrations `202608220001` and `202608220002`.
- The public GitHub release is built from the same tested 0.5.0 source line and publishes the Windows installer, Windows portable archive, Android APK, and a SHA-256 sidecar for each package.
- Automated analysis, unit and stress regression, Android package verification, Windows build gating, bilingual website checks, and anonymous download checks passed before publication.
- Hardware-dependent behavior still requires the manual checklist in [Android player acceptance](../testing/MOBILE_PLAYER_TEST_PLAN.md), especially Bluetooth, real calls, screen-off playback, OEM battery saving, and Windows Profile measurements.

## 简体中文

**[English](#sona-050-public-preview)** · 简体中文 · [下载](https://github.com/Owl-Lee/Sona-Player/releases/latest)

Sona 0.5.0 是面向 Windows 与 Android 的数据安全、资料可控性、性能和稳定性更新。本地播放仍然是核心体验；云同步与联网识别继续作为可选增强，不是播放器运行的前提。

## 主要更新

### 可恢复的云端管理

- 删除云端歌曲时，云副本会进入回收站并保留 30 天，不再立刻销毁。
- 刚删除的歌曲可在提示中立即撤销；回收站中的任意歌曲也可以从回收站页面恢复。
- 永久删除和清空回收站是明确的所有者操作，会删除云端记录与不再被引用的云媒体，但绝不会删除本地文件。

### 完整备份与恢复

- 手动导出的 `.sonabackup` 是自包含备份：包含 SQLite 曲库、保存在该数据库中的 Sona 设置、已导入的歌曲和 MV，以及由 Sona 管理的封面、歌单图片和自定义背景。
- 备份全程采用流式读写和校验；恢复前会完整验证，并在下次冷启动时替换曲库，同时保留一份恢复前数据库作为回退。
- 轻量自动恢复快照默认保留最近三份数据库与图片状态，不会反复复制整个媒体库。它用于同一设备恢复；换设备、卸载应用或迁移签名前，请手动导出完整备份。
- 账号登录会话和云端凭据不属于备份内容；在另一套安装中恢复后需要重新登录。
- 完整备份当前不加密，其中可能包含媒体和个人曲库资料，请像保管原始媒体一样妥善保管。

### 用户可控的歌曲资料

- 智能识别继续组合媒体标签、文件名清理、MusicBrainz，以及可选的 Chromaprint / AcoustID 声纹匹配。
- 识别结果会先预览，再由用户确认是否修改曲库。
- 可以手动编辑歌名、歌手、专辑和封面。
- 识别与手动编辑都会生成逐曲历史；安全撤销不会覆盖此后发生的无关新修改。

### 性能档位

- 设置中可以选择 **完整特效**、**节能特效** 或 **关闭动态特效**。
- 档位会联动动画频率、粒子数量、模糊强度、图片缓存预算、黑胶动画和 Windows 视频输出，同时保留壁纸与主题配色。
- 皮肤选择器和全屏特效减少了重复图片解码，也避免不必要地反复创建原生视频表面。

### 播放与手机端稳定性

- 快速连续播放、暂停、上一首和下一首会按序执行，使声音、歌名、封面、时长、队列高亮和 MV/唱片页面最终统一到同一首当前歌曲。
- 队列切换、逐曲媒体能力判断、云端重复点击、删除边界、损坏备份、资料撤销和性能档持久化均有专项回归覆盖。
- 正式签名 Android 包已在 Android 16 真机上验证冷启动、切入后台与恢复、媒体会话、临界内存回调下保持存活，以及不清除应用数据的重新启动。
- 来电、蓝牙设备和厂商省电策略会因机型不同而变化；如遇设备特有的中断问题，请同时提供手机型号和 Android 版本。

## 下载与安装

Release 附件使用固定文件名，每个安装包都附带对应的 `.sha256` 校验文件。

- **Windows 安装器：**`Sona-Windows-x64-Setup.exe`
- **Windows 便携版：**`Sona-Windows-x64.zip`——请完整解压后再运行 `sonar_vault.exe`。
- **Android：**`Sona-Android.apk`

### Android 签名与升级

Sona 的永久 Android 签名从官方 0.4.51 版本开始启用。官方 0.5.0 APK 可以直接覆盖官方 0.4.51，且不会清除应用数据。

更早的 0.4.50 预览版使用开发证书；本地自行构建或第三方 APK 也可能使用其他证书。Android 无法用 0.5.0 覆盖不同签名的 APK。如果系统提示签名冲突，请先保留原始媒体并同步需要保留的云端资料，然后卸载一次不同签名的旧版，再安装官方 0.5.0。卸载会清除 Sona 应用私有目录里的曲库数据库、设置和自动快照，但不会删除普通共享目录中的媒体文件。

### Windows 签名提醒

Windows 安装包目前没有 Authenticode 代码签名，Microsoft Defender SmartScreen 可能显示 **Unknown publisher（未知发布者）**。请只从 Sona 官网或本 GitHub Release 下载，并在运行前使用对应 `.sha256` 文件验证安装包。

> Sona 0.5.0 仍是公开预览版。重要媒体请始终保留独立副本，并在外部位置保存一份手动导出的完整备份。
