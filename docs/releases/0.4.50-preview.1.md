# Sona 0.4.50 Public Preview

**English** · [简体中文](#简体中文) · [Download](https://github.com/Owl-Lee/Sona-Player/releases/tag/v0.4.50-preview.1)

This is Sona's first public preview for Windows and Android.

## Included in this preview

- Local-first, offline-ready music and MV playback.
- Local library, search, favorites, recents, playlists, queue, and listening charts.
- Folder scanning, SHA-256 duplicate detection, and a local SQLite library.
- Liquid-glass themes, an immersive vinyl player, custom backgrounds, and theme-specific effects.
- Smart metadata cleanup with optional Chromaprint / AcoustID fingerprint fallback.
- Simplified Chinese, Traditional Chinese, and English interfaces.
- Account and cloud-sync foundations; cloud failures do not block local playback.

## Install

- **Windows:** download `Sona-Windows-x64.zip`, extract the complete archive, then run `sonar_vault.exe`. Do not copy the executable by itself.
- **Android:** download and install `Sona-Android.apk`. This preview uses a development signature, so Android may show an unknown-source warning. Download only from the official release or Sona website.
