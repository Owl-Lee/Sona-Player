# Sona 0.4.51 Public Preview

**English** · [简体中文](#简体中文) · [Download](https://github.com/Owl-Lee/Sona-Player/releases/tag/v0.4.51-preview.1)

Sona 0.4.51 is a reliability and distribution update for Windows and Android. It keeps the local-first player experience while tightening queue behavior, metadata identification, responsive layout, and release signing.

## Highlights

- Reduced unnecessary player, library, home, ranking, and now-playing rebuilds.
- Reduced theme-picker decoding, fullscreen effects, and glass-compositing work for smoother interaction.
- Added full-library identification while keeping single-track review available.
- Improved cloud-library batch selection and deletion on desktop and mobile.
- Kept the compact mobile player visibly separated from page content.
- Introduced Sona's permanent Android release certificate for future in-place updates.

## Install

- **Windows:** download `Sona-Windows-x64.zip`, extract the complete archive, then run `sonar_vault.exe`. Do not copy the executable by itself. The preview is not yet Authenticode-signed, so Windows may show SmartScreen or an Unknown publisher warning.
- **Android:** download and install `Sona-Android.apk`. Android may ask you to allow installs from your browser or file manager because this is a direct APK download.

### One-time Android upgrade notice

The 0.4.50 preview used a development certificate. Android cannot install 0.4.51 over that build. If you installed 0.4.50, preserve or sync anything important, uninstall it once, and then install 0.4.51. Uninstalling clears Sona's app-local database and settings; music files stored outside the app remain untouched. Fresh installations and all upgrades starting with 0.4.51 use the permanent certificate and can update in place.

## 简体中文

**[English](#sona-0451-public-preview)** · 简体中文 · [下载](https://github.com/Owl-Lee/Sona-Player/releases/tag/v0.4.51-preview.1)

Sona 0.4.51 是面向 Windows 与 Android 的稳定性和分发更新。在保留本地优先播放器体验的同时，进一步修正了队列、歌曲识别、响应式布局与发布签名。

### 主要更新

- 减少播放器、曲库、主页、排行和播放页不必要的重复重建。
- 减少皮肤选择器图片解码、全屏特效与毛玻璃合成开销，让交互更流畅。
- 加入全曲库识别，同时保留单曲结果预览与确认。
- 改进电脑端和手机端云端曲库的批量选择与删除。
- 让手机紧凑播放栏与页面内容始终保留清晰的小间距。
- 启用 Sona 永久 Android 发布证书，后续版本可以直接覆盖升级。

### 安装

- **Windows：**下载 `Sona-Windows-x64.zip`，完整解压后运行 `sonar_vault.exe`，不要只单独复制 EXE。当前预览版尚未使用 Authenticode 代码签名，因此 Windows 可能显示 SmartScreen 或“未知发布者”提示。
- **Android：**下载并安装 `Sona-Android.apk`。由于安装包通过网站直接下载，Android 可能要求允许浏览器或文件管理器“安装未知应用”。

#### Android 一次性升级提醒

0.4.50 预览版使用了开发证书，Android 无法直接用 0.4.51 覆盖。安装过 0.4.50 的用户请先保存或同步重要内容，卸载旧版一次，再安装 0.4.51。卸载会清除 Sona 的应用内数据库和设置，但不会删除存放在应用外部的音乐文件。全新安装以及从 0.4.51 开始的后续升级均使用永久证书，可以直接覆盖更新。
